Data spine

The data spine is the set of tables and jobs that every integration uses. A record comes in, gets a Flow identity, and goes out from a Flow record.

Sources · Data spine · Data model · server core · 21 Oct 2026
01

Name match

A name match joins a Flow customer to an accounts contact by the same name. A send to Xero still finds the contact this way.

02

Four tables

The data spine is four tables in the Flow database. Every installation creates the tables when the server starts.

03

One path

The path is the route a record takes from an outside system into Flow and back. The outbox send on this path is not in use.

04

Identity map

The identity map pairs one Flow record with one outside record. One active link is the pair Flow trusts.

05

Job queue

The job queue is the table of background work that waits to run. A worker claims a job and holds a lease.

06

Outbox

The outbox is the table of writes Flow will send to an outside system. Flow stores the write row before the call leaves.

07

Review queue

The review queue is the list of differences a person must decide. An item alerts the person and writes to no system.

08

Field owners

A field owner is the one system that may change that fact on a billed job. Flow compares the work fields only.

09

Three-way compare

The three-way compare checks a job after Flow has drafted its invoice. Flow looks at the basis, the work system and its own draft.
