# feat: link an already billed invoice and retain the Flow duplicate

Related: #441
Related: #443

## What Problem This Solves

A refused issued invoice could point to an existing Xero bill without a safe
way to associate its job and retain the extra Flow record. Job panels also
omitted the accounting candidates that explain ambiguous/conflicting links.

## User Impact

Owners and admins can compare the actual matched invoice, then explicitly
Link to Xero invoice. One transaction associates the jobs and retains the
Flow record as Duplicate, separately from cancelled invoices. Numbers and
issued versions remain, the preview is marked Duplicate, retries are
idempotent, and the jobs cannot draft again. Job panels expose safe links
and accounting candidate facts. Nothing is written or emailed in Xero.

## Why This Change Was Made

Reuse the existing terminal storage status, core ledger events and adapter
mirror behind the integration port. A single resolution receipt distinguishes
Duplicate from Void without duplicating the lifecycle. A database constraint
requires every duplicate receipt to be terminal. Evidence fingerprints and
row locks reject changed comparisons and competing send intent.

Candidates require the retained refusal id, a fresh complete same-tenant-era
mirror, the linked client/currency, an approved/paid sales invoice and all
issued products with identical quantity/line amount/tax. Reference alone
never proves the work. A candidate first seen before reconnection is refused
because old mirror rows lack tenant provenance. Confirmation is the person's
decision, not an automatic business-identity assertion. Existing legitimate
Void remains available, with a compare-first reminder for a possible match.

No optional bypass, issued Delete, new fee, placeholder rule, live cleanup,
release, merge, deployment or publication. Neither issue is closed.
