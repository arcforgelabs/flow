## What Problem This Solves

Lab-rule holds lost their rule name and instructions on invoice pages. Three separate renderers disagreed. Historical invoices with extra charges could be discarded as candidates, allowing the matcher to say no invoice existed.

This is a partial source delivery. It does not close either issue.

## User Impact

Draft, issued and list flows share a hold presenter with the full reason, matched links and next steps. Non-chargeable list rows explain their rule. A possible historical invoice with matching Reference and job products stays for review despite a different total. Job wording no longer declares an ambiguous invoice absent.

## Why This Change Was Made

Reuse the existing Notice, links, rule payload and reference owner. Keep exact-match decisions unchanged. No fee assumption, automatic accounting link, schema change, bypass, number change or issued-version mutation is included.

The explicit Link to Xero invoice / retained Duplicate workflow is not implemented: disposable database proof is blocked. Delete retention semantics still need a decision. Full acceptance map and per-hold audit: docs/evidence/invoice-completion/acceptance.txt.
