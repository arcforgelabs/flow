## Root cause boundary

The existing matcher requires an amount match or a prior link. An invoice with the same client, reference and all job products plus a fee was removed before scoring. The fresh mirror then allowed “not_found”, which can permit another draft and skip the live duplicate check. The repair retains that evidence as ambiguous. It adds no shipping assumption and never uses a reference alone as an exact link. Candidate search keeps the existing client/date/rejection/taken-amount guards. Old checked jobs are re-evaluated on the next existing source or mirror change; no automatic production backfill runs.
