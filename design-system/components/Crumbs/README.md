# Crumbs

The trail above a page one level down, back to the page it came from.

- `crumbs([href, label]…, here)`: each earlier page is a link; the last item is this page.
- Rules › Invoices, Integrations › Xero › History.

Code: `crumbs` in `server/ui/kit.js`; `.fx-crumbs` in `server/ui/flow.css`.
