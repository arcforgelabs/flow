# InvoiceProblems

Invoice holds name the check, retain its full reason, and link matched records and next steps.

- One owner serves draft pages, issued pages and Pending list cells.
- Page notices retain all sentences on phones. A short label never replaces the fix.
- Compact lists show one short check name and a count, clipped inside their column. Full reasons stay on hover and in the accessible name. Open the invoice through its existing row/client link for every reason and safe matched/remediation link. No clipped or overlapping controls are added to the metadata line.
- Xero links use a fixed origin and validated invoice id. Source links accept HTTP(S) only.

Code: `invoiceProblems` in `server/ui/invoice-problems.js`.
