# Icon

Lucide icons, drawn in the text colour.

- `lucide(h, name, label)`. With a label it is named for a screen reader; without, it is hidden from one.
- An icon goes before a word, or alone on a control with a name (see Tip).
- Any Lucide name works in the app (`/assets/icons/<name>.svg`).

Code: `lucide` in `server/ui/custom-fields.js`.
